# Keyboard — Gboard transparent background patch

Проект содержит экспериментальный патч для **Gboard 18.3.1.977415014 arm64-v8a** на Android 11.

## Что делает патч

Патч изменяет бинарные таблицы тем Gboard (`assets/theme/*.binarypb`) и заменяет фоновые цвета следующих слоёв на `ARGB 0x00000000`:

- `keyboard-background`;
- `keyboard-body-area`;
- `keyboard-base-area`;
- `keyboard-header-area`;
- отдельные overlay-слои темы и плавающего режима.

Фон клавиш намеренно не изменяется.

## Текущее состояние

Проверка на устройстве показала, что часть верхней панели и буфер обмена всё ещё имеют собственный непрозрачный фон, а экран переводчика падает. Это означает, что текущий патч неполный: эти компоненты используют отдельные панели/ресурсы и требуют отдельного анализа. Регулятор прозрачности в настройках пока **не реализован**.

## Содержимое

- `tools/patch_theme_pb.py` — патчер protobuf-таблиц тем;
- `tools/build_apk.py` — сборка APK из исходного APK и изменённых тем;
- `tools/analyze_pb.py` — вспомогательный декодер таблиц через `protoc`;
- `patches/gboard-18.3.1/assets/theme/` — snapshot изменённых theme-файлов;
- `docs/` — диагностические материалы и ограничения.

## Сборка

Оригинальный APK намеренно не включён в репозиторий. Положите файл Gboard рядом со скриптом сборки и настройте пути в `tools/build_apk.py`. Для подписи потребуются Android Build Tools (`zipalign`, `apksigner`) и собственный локальный ключ.

Патчированный APK после пересборки будет подписан не ключом Google, поэтому поверх официальной установки он обычно не устанавливается. Сначала включите резервную клавиатуру, затем удалите старую патченную/официальную версию только если это необходимо для теста.

## Важно

Репозиторий публичный. В него не добавляются оригинальный APK Gboard, готовые APK, keystore-файлы, личные ключи или подписи Google.
