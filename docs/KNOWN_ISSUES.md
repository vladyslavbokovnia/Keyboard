# Known issues after v2

Тестовая сборка `Gboard-18.3.1-transparent-v2.apk` была проверена на Android 11.

Наблюдения:

1. Основная область клавиатуры стала прозрачной.
2. Верхняя панель осталась непрозрачной.
3. Панель буфера обмена осталась непрозрачной.
4. Открытие переводчика приводит к падению приложения.
5. Настройка регулировки прозрачности отсутствует.

Вероятная причина: верхняя панель, буфер обмена и переводчик используют отдельные widget/panel-правила, не покрытые общими селекторами `keyboard-*`. Следующий этап должен декомпилировать `classes*.dex`, сопоставить stack trace падения переводчика и отдельно обработать панели, не обнуляя фон клавиш и интерактивных карточек.

Оригинальный APK и пользовательский keystore в репозиторий не добавляются.
